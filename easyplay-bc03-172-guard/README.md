# CarConnect 0.1.10 beta · BC03 1.7.2 SPP 保护与接入测试

分支 `codex/bc03-172-k2001n`。将 OEM 0.1.10 的清理保护适配到已核对的 BC03 1.7.2 / gocsdk，保留原 1.7.2 分支的限时数据验证、音频缓冲及全屏恢复，同时保留 OEM 的首帧恢复。

[下载 APK 和源码](https://github.com/beidouxiaonan/CarConnect/releases/tag/v0.1.10-beta-bc03-172-spp-guard-test)。APK：`CarConnect-0.1.10-beta-BC03-1.7.2-SPP-guard-test-Android4.2-4.4.apk`；显示版本 `Carplay-connect-0.1.10-beta-BC03-172-SPP-guard-test`，code53，包名 `com.shihab.diplay.legacy`。

## 安装与连接

1. **覆盖安装，保留数据，不卸载。** 同测试证书，已选 iPhone、热点、音量、自动连接偏好保留。普通 APK，无需 Root。
2. 确认原车蓝牙已连接那台已配对 iPhone，车机热点及 iPhone Wi-Fi 开启。使用无线模式，启用“使用原车蓝牙连接 iPhone”；已保存手机不用重选。
3. 新“允许底层 SPP 恢复（实验，默认关闭）”先保持关闭。旧清理开关不会自动开启底层恢复。
4. 再启用自动连接，等待完整一轮。如果旧状态仍占用，先关闭自动连接，在无通话时人工关闭再开启原车蓝牙、连接已配对手机，然后再开启自动连接。人工开关会中断通话/蓝牙音乐，也不能保证固件清除缓存。

目标包括已提供系统样本的 K2001N_HDKJ_S112406 / QuadCore-T3 / BC03 1.7.2。**该机型此前有线启动整机重启问题尚未修复，请保持无线模式。** 本包不是 SD8227 启动兼容包。

## 本次行为

- SPP 空闲稳定 300ms，直接继续连接，不请求断开、不发送 VH。
- 清理请求前用 `commit()` 保存未完成标记；未确认释放时暂停当前服务自动重试。冷却结束、重开应用、正常重启均不会重复清理该未完成请求；确认通道空闲后清除标记。保存的自动连接偏好不变。
- 底层恢复独立开关默认关闭。只有明确开启时，原接口未释放才允许一次已核对的 VH；仍未释放就暂停。写出命令不代表释放成功。
- 保留 1.7.2 接入：VF 发出后等 15 秒；仅已核对 1.7.2 且状态仍缺失时做一次数据验证，8 秒无接收数据就关闭本应用客户端。仍由原有 iAP2 握手判定协议，不把字节收发或缺失状态当作 CarPlay 成功。
- VF 请求仍有 45 秒保护窗口；窗口内不发送新 VF、不进行 SPP 清理，手动解除清理暂停也不能跳过它。真实收到协议数据的旧客户端关闭后才可清除自己的 VF 等待，旧会话不能清除新请求。

暂停后先恢复原车蓝牙，再关闭/开启自动连接。确需再次清理时，关闭自动连接并等待任务退出，点“允许再次清理一次”再开启；按钮仅解除本应用未完成标记，不直接发命令。正在连接或持有数据通道时拒绝；进程内清理冷却继续生效。

## 诊断与适用边界

| 最后阶段 | 含义 |
|---|---|
| P1 / 未完成清理标记 | 本轮已暂停，避免循环断开；尚未发送 VF |
| C3 / C5 | 服务未连接状态稳定，才允许下一步 |
| S2 | VF 已写入，不证明原车接受 |
| S3 未上报 SPP | 1.7.2 的一次限时数据验证，尚未完成 iAP2 |
| S6 8 秒无数据 | 接入没有收到回包；关闭本应用客户端 |
| R1 / R2 / R3 | 无线控制启动后的首帧计时 / 首帧显示 / 有限重连 |

最低 API17（Android 4.2），覆盖 Android 4.4 / 4.4.2 的 API19；纯 V1、ARMv7。1.7.2 样本的 `Bluetooth.apk` 标注 API25，不能据文件或营销版本号认定运行车机一定是 4.4，请以设备 SDK_INT 为准。编译/签名兼容性检查不等于每台车机运行已通过。

运行仍检查 BC03 APK、Binder schema 和 gocsdk 的精确指纹。1.7.9 / 1.3.6 原有指纹也保留，但只有 1.7.2 启用缺失状态的数据验证。**不需要安装或替换 BC03、Bluetooth.apk、gocsdk 系统文件。** 不改系统缓存、不删除配对、不伪造广播、不强制抢占占用中的通道。

96 项主机回归、签名和载荷检查通过，**本版未做目标车机实测，不保证持续占用已经解除或无线已恢复**。失败时复制“原车通道诊断”和“诊断信息”两份完整文本私下反馈；不连续清理碰运气。
